Émilie's Birthday Garden — start here

This folder is a complete static website. It does not need Node, npm, or a build step.

HOW TO PLAY
• Open the page in Chrome, Safari, Edge, or Firefox on a laptop/desktop.
• Move the mouse: Émilie follows the pointer.
• Click a glowing spot to dig up a seed.
• Click a garden plot to plant it, then click it again to water it.
• Grow all six flowers, then click the gift when it floats down.
• Click villagers to hear their birthday messages.
• On the title screen, click or press Space.
• The birthday letter has a Japanese / English button.
• A mouse works much better than a trackpad, and the game is not designed for phones.

IMPORTANT: DON'T DOUBLE-CLICK index.html
Browsers block fonts and images on file:// pages. Use one of the options below.

HOST IT (EASIEST WAY TO SEND A LINK)
Option 1 — Netlify Drop
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. Sign in if asked, then copy the https://...netlify.app link and send it to her.

Option 2 — Cloudflare Pages
1. Go to https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
2. Upload this folder. Leave the build command and output directory empty.

Option 3 — GitHub Pages
1. Put these files in a GitHub repository (index.html must be at the top level).
2. Repo → Settings → Pages → Deploy from a branch → main → /(root).
3. Send her the github.io link after it goes live.

Option 4 — Send the ZIP
Send her emilies-birthday-game.zip. On a Mac, she can unzip it, open Terminal, and run:
    cd ~/Downloads/emilies-birthday-game-share
    python3 -m http.server 8000
Then open http://localhost:8000 in her browser.
On Windows, run `py -m http.server 8000` from inside the unzipped folder instead.

Any static host works. There is no server-side code.
